# Sprint Context Panel — Help Tooltips

Tooltip text only, one section per UI element. User-facing language, each under 150 chars. Consumed by the frontend feature slice; downstream agents treat this file as optional.

## Sprint Context button (top bar)
Open the sprint context panel — anonymized Fokus metrics for the sprint(s) this retro covers.

## Panel header (multi-sprint)
This retro covers more than one sprint. Each section below shows the metrics for one of them.

## Completion rate
Share of planned work the team finished in the sprint, as Fokus measured it.

## Disruption rate
How much work was added or changed mid-sprint. Higher means the plan shifted more after the sprint started.

## Carry-over rate
Share of work that wasn't finished and rolled into the next sprint.

## Health score
Fokus's overall sprint health, combining the rates above. Color shows the band: green, amber, or red.

## Rate indicator color
Color reflects how this rate scored against Fokus's healthy range for it.

## Added mid-sprint block
Tickets added after the sprint started — shown when disruption was high. Keys and titles only, never who they were assigned to.

## "+N more" (scope additions)
More tickets were added than shown here. Open Fokus for the full list.

## Cached / last-known badge
Live Fokus data wasn't reachable, so this shows the last synced values for the sprint.

## Unavailable section
This sprint hasn't been synced from Fokus yet, so there are no metrics to show.
